# FR_R0024 ResourceSemaphoreWaits

| Field | Value |
|---|---|
| RuleId | `FR_R0024_ResourceSemaphoreWaits` |
| Category | Memory |
| Severity | High |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.4 |
| Lifecycle | Active |
| Data source | `FR_Wait` |
| Dedup anchor | window (D-074); folds FR_R0005 (§7.13) |

## What it detects

RESOURCE_SEMAPHORE waits in the window (query memory-grant pressure).

## How it is computed

Repository-only (D-014/D-081). Any RESOURCE_SEMAPHORE wait with positive wait time fires.

## Severity rationale

High — queries are queuing for memory grants.

## Confidence rationale

High — observed.

## Evidence-type rationale

Observed.

## False-positive risks

A momentary grant-wait under a big query reports.

## False-negative risks

Sub-minute waits between snapshots are missed.

## Drill-down guidance

Review large memory-grant queries and MAX_GRANT_PERCENT; the folded FR_R0005 sessions are in MoreInfo. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0024_ResourceSemaphoreWaits';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed FR_Wait with a RESOURCE_SEMAPHORE wait.
