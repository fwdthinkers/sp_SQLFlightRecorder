# FR_R0015 QueryPlanRegression

| Field | Value |
|---|---|
| RuleId | `FR_R0015_QueryPlanRegression` |
| Category | QueryStore |
| Severity | High |
| Confidence | Medium |
| Evidence type | Inferred |
| Introduced in | 0.3 |
| Lifecycle | Active |
| Data source | `FR_QueryStoreTopN` |
| Dedup anchor | db+query (D-074, AnchorKey) |

## What it detects

A query whose recent plan is materially slower than a prior plan (Query Store).

## How it is computed

Repository-only (D-014/D-081). Latest captured plan vs best prior plan for the same query; fires above `QueryStoreRegressionFactor`. On SQL 2016 Confidence is forced down (runtime stats only, D-107).

## Severity rationale

High — a regression directly degrades a query.

## Confidence rationale

Medium (Low on 2016).

## Evidence-type rationale

Inferred.

## False-positive risks

Parameter-sensitive plans can look like regressions; short samples mislead.

## False-negative risks

Queries without a prior plan in the window are not compared. Folds FR_R0016 for the same query (§7.13).

## Drill-down guidance

Review the query in Query Store; do not force a plan automatically. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0015_QueryPlanRegression';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`QueryStoreRegressionFactor`. See [configuration.md](../configuration.md).

## Example

Seed FR_QueryStoreTopN with a regressed plan for a query (see tests/rules/).
