# FR_R0016 TopCpuConsumerInWindow

| Field | Value |
|---|---|
| RuleId | `FR_R0016_TopCpuConsumerInWindow` |
| Category | QueryStore |
| Severity | Medium |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.3 |
| Lifecycle | Active |
| Data source | `FR_QueryStoreTopN` |
| Dedup anchor | db+query (D-074, AnchorKey) |

## What it detects

The queries that accumulated the most CPU in the window (Query Store).

## How it is computed

Repository-only (D-014/D-081). Top-5 by total CPU across the window; duration/reads carried as supplementary evidence.

## Severity rationale

Medium.

## Confidence rationale

High — aggregated from observed QS stats.

## Evidence-type rationale

Observed.

## False-positive risks

A heavy but legitimate query is still 'top CPU'.

## False-negative risks

Only the top 5 are reported; folded into FR_R0015 when the same query regressed.

## Drill-down guidance

Review the query for tuning; confirm it is representative of the incident. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0016_TopCpuConsumerInWindow';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed FR_QueryStoreTopN with several queries of differing total CPU.
