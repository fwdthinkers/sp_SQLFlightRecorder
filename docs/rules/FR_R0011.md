# FR_R0011 MaintenanceJobOverlap

| Field | Value |
|---|---|
| RuleId | `FR_R0011_MaintenanceJobOverlap` |
| Category | Maintenance |
| Severity | Medium |
| Confidence | Medium |
| Evidence type | Inferred |
| Introduced in | 0.2 |
| Lifecycle | Active |
| Data source | `FR_AgentJob` |
| Dedup anchor | job (D-074) |

## What it detects

A maintenance job that ran during or across the incident window.

## How it is computed

Repository-only (D-014/D-081). Jobs whose name matches `MaintenanceJobNamePatterns` and whose run overlapped the window.

## Severity rationale

Medium.

## Confidence rationale

Medium — overlap is inferred correlation.

## Evidence-type rationale

Inferred.

## False-positive risks

Maintenance overlapping an unrelated incident is coincidental.

## False-negative risks

Custom job names not in the pattern list are missed.

## Drill-down guidance

Confirm whether the maintenance activity coincided with the symptoms. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0011_MaintenanceJobOverlap';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`MaintenanceJobNamePatterns`. See [configuration.md](../configuration.md).

## Example

Seed FR_AgentJob with a matching maintenance job overlapping the window.
