# FR_R0009 TempdbFileImbalanceOrPressure

| Field | Value |
|---|---|
| RuleId | `FR_R0009_TempdbFileImbalanceOrPressure` |
| Category | Tempdb |
| Severity | Medium |
| Confidence | Medium |
| Evidence type | Inferred |
| Introduced in | 0.2 |
| Lifecycle | Active |
| Data source | `FR_Tempdb` |
| Dedup anchor | window (D-074) |

## What it detects

Tempdb data files differ substantially in size (allocation-contention risk).

## How it is computed

Repository-only (D-014/D-081). Flags when max data-file size exceeds 2x the min and there is more than one file.

## Severity rationale

Medium.

## Confidence rationale

Medium — imbalance is a risk indicator, not a confirmed problem.

## Evidence-type rationale

Inferred.

## False-positive risks

Auto-grow transients can momentarily unbalance files.

## False-negative risks

Equal-sized but insufficient files are not flagged by this rule.

## Drill-down guidance

Confirm tempdb files are equally sized and pre-grown; check allocation waits. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0009_TempdbFileImbalanceOrPressure';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed FR_Tempdb with min/max data-file sizes differing >2x.
