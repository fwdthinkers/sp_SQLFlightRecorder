# FR_R0021 ConfigurationChangeInWindow

| Field | Value |
|---|---|
| RuleId | `FR_R0021_ConfigurationChangeInWindow` |
| Category | Configuration |
| Severity | Medium |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.4 |
| Lifecycle | Active |
| Data source | `FR_Configuration` |
| Dedup anchor | config name (D-074) |

## What it detects

A tracked server/database configuration value changed during the window.

## How it is computed

Repository-only (D-014/D-081). `LAG` over captured configuration values; a change in value across snapshots fires.

## Severity rationale

Medium.

## Confidence rationale

High — observed diff.

## Evidence-type rationale

Observed.

## False-positive risks

An intended change reports (correctly — it is context).

## False-negative risks

Changes that revert between snapshots may be missed.

## Drill-down guidance

Correlate the change time with the incident; confirm intent. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0021_ConfigurationChangeInWindow';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed FR_Configuration with a value that changes across snapshots.
