## Why it is disabled

Plan analysis is **disabled by design**. The original implementation shredded plan XML from `sys.dm_exec_query_plan`, which locked decisions **D-015, D-046, D-082, and D-136** forbid. There is no compliant implementation, so this rule has no logic and never fires. `@IncludeQueryPlans = 1` is a reserved no-op that emits a single Informational coverage finding explaining this. The RuleId is preserved and never reused (D-089/D-090); the rule may be revisited only under a future decision-log-approved plan-analysis design.

## What it would have detected

Optimizer warnings in a plan.

## Alternative

For plan-level evidence without this tool parsing plan XML, use **Query Store** (see FR_R0015/FR_R0016/FR_R0018).

## Guarantees

- No `sys.dm_exec_query_plan`. No T-SQL plan-XML shredding.
- RuleId preserved, never reused (D-089).
- Enforced by the static-analysis linter (D-136/D-144).
