## What it detects

Query Store found no QS-enabled user database (coverage gap).

## How it is computed

Repository-only (D-014/D-081). The most recent QueryStore collector step reported Skipped in the window.

## Severity rationale

Informational (coverage).

## Confidence rationale

High — repository signal.

## Evidence-type rationale

Observed.

## False-positive risks

Intentionally QS-disabled shops see this every report (by design).

## False-negative risks

n/a — it reports absence.

## Drill-down guidance

Consider enabling Query Store on key databases for future plan-level evidence. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0017_QueryStoreDisabledOnUserDbs';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`CollectQueryStore`. See [configuration.md](../configuration.md).

## Example

Report with no QS-enabled DB; the QueryStore step is Skipped.
