# FR_R0006 ServerRestartDuringWindow

| Field | Value |
|---|---|
| RuleId | `FR_R0006_ServerRestartDuringWindow` |
| Category | Configuration |
| Severity | Critical |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.1 |
| Lifecycle | Active |
| Data source | `FR_InstanceSnapshot.SqlStartTimeUtc`, `FR_ErrorLog` (corroboration) |
| Dedup anchor | window (D-074) |

## What it detects

A SQL Server restart inside the report window.

## How it is computed

Repository-only (D-014/D-081). The captured start time changing within the window means a restart; the window is split at the boundary and delta rules re-anchor at the first post-restart snapshot (D-064).

## Severity rationale

Critical (informational) — cross-restart cumulative deltas are meaningless; the reader must know.

## Confidence rationale

High — the start-time change is directly observed.

## Evidence-type rationale

Observed.

## False-positive risks

A planned restart still reports (correctly — it is context, not blame).

## False-negative risks

If instance snapshots are missing, the error-log corroboration path is the fallback.

## Drill-down guidance

Confirm whether the restart was expected; analyze pre/post segments separately. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0006_ServerRestartDuringWindow';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed two FR_InstanceSnapshot rows with different SqlStartTimeUtc.
