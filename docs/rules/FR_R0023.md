# FR_R0023 ThreadpoolWaitsObserved

| Field | Value |
|---|---|
| RuleId | `FR_R0023_ThreadpoolWaitsObserved` |
| Category | Waits |
| Severity | Critical |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.4 |
| Lifecycle | Active |
| Data source | `FR_Wait` |
| Dedup anchor | window (D-074) |

## What it detects

THREADPOOL waits recorded in the window (worker-thread starvation).

## How it is computed

Repository-only (D-014/D-081). Any THREADPOOL wait with positive wait time in the window fires.

## Severity rationale

Critical — worker starvation can freeze the instance.

## Confidence rationale

High — observed.

## Evidence-type rationale

Observed.

## False-positive risks

A brief THREADPOOL blip under momentary load reports.

## False-negative risks

Sub-minute starvation between snapshots is missed.

## Drill-down guidance

Investigate blocking chains and session counts; review max worker threads only after confirming sustained starvation. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0023_ThreadpoolWaitsObserved';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None (wait ignore list does not exclude THREADPOOL). See [configuration.md](../configuration.md).

## Example

Seed FR_Wait with a THREADPOOL wait.
