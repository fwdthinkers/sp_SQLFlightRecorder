# FR_R0008 TempdbVersionStoreGrowth

| Field | Value |
|---|---|
| RuleId | `FR_R0008_TempdbVersionStoreGrowth` |
| Category | Tempdb |
| Severity | Medium |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.2 |
| Lifecycle | Active |
| Data source | `FR_Tempdb` |
| Dedup anchor | window (D-074) |

## What it detects

The tempdb version store grew during the window.

## How it is computed

Repository-only (D-014/D-081). Compares min/max `VersionStoreKb` across the window; escalates when max >= `TempdbVersionStoreWarnKb`.

## Severity rationale

Medium, escalating on size.

## Confidence rationale

High — observed from tempdb space usage.

## Evidence-type rationale

Observed.

## False-positive risks

Normal snapshot-isolation workloads grow the version store benignly.

## False-negative risks

Growth that fully drains between snapshots is missed.

## Drill-down guidance

Find long-running / open transactions holding versions (FR_R0002); check snapshot isolation usage. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0008_TempdbVersionStoreGrowth';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`TempdbVersionStoreWarnKb` (default ~5 GB). See [configuration.md](../configuration.md).

## Example

Seed FR_Tempdb with rising VersionStoreKb.
