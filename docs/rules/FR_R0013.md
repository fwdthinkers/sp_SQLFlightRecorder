# FR_R0013 DeadlocksObserved

| Field | Value |
|---|---|
| RuleId | `FR_R0013_DeadlocksObserved` |
| Category | Blocking |
| Severity | High |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.2 |
| Lifecycle | Active |
| Data source | `FR_Deadlock` |
| Dedup anchor | graph hash (D-074) |

## What it detects

One or more unique deadlock graphs captured during the window.

## How it is computed

Repository-only (D-014/D-081). Distinct deadlock graphs (deduped by hash, D-053) with a deadlock time in the window.

## Severity rationale

High — deadlocks are real, actionable failures.

## Confidence rationale

High — observed graphs.

## Evidence-type rationale

Observed.

## False-positive risks

A single benign deadlock still reports (correctly).

## False-negative risks

Deadlocks not captured by system_health are not seen.

## Drill-down guidance

Review the stored graph and participating queries; NOLOCK is not a remedy. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0013_DeadlocksObserved';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed FR_Deadlock with a graph in the window.
