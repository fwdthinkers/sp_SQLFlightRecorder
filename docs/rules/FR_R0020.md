# FR_R0020 HighCompilationRate

| Field | Value |
|---|---|
| RuleId | `FR_R0020_HighCompilationRate` |
| Category | PlanCache |
| Severity | Medium |
| Confidence | Medium |
| Evidence type | Inferred |
| Introduced in | 0.3 |
| Lifecycle | Active |
| Data source | `FR_PlanCacheSummary` |
| Dedup anchor | window (D-074) |

## What it detects

Sustained high SQL compilation pressure.

## How it is computed

Repository-only (D-014/D-081). Rate derived from raw cumulative compilation counters via window delta from `@DeltaStartUtc` (D-007); fires above `CompilationsPerSecWarn`.

## Severity rationale

Medium.

## Confidence rationale

Medium — a rate signal, not a confirmed cause.

## Evidence-type rationale

Inferred.

## False-positive risks

A legitimate ad-hoc-heavy workload shows high compilation.

## False-negative risks

Counter reset on restart is excluded; brief spikes are averaged out.

## Drill-down guidance

Review ad-hoc workload and parameterization; do not clear the plan cache reflexively. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0020_HighCompilationRate';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`CompilationsPerSecWarn`. See [configuration.md](../configuration.md).

## Example

Seed FR_PlanCacheSummary with rising compilation counters.
