# FR_R0002 LongRunningOpenTransaction

| Field | Value |
|---|---|
| RuleId | `FR_R0002_LongRunningOpenTransaction` |
| Category | Blocking |
| Severity | Medium |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.1 |
| Lifecycle | Active |
| Data source | `FR_Request` |
| Dedup anchor | `SessionId` (D-074) |

## What it detects

A session holding an open transaction across multiple snapshots for a long interval.

## How it is computed

Repository-only (D-014/D-081). No elapsed column is stored, so duration is inferred from persistence: `OpenTransactionCount > 0` in >= 2 snapshots (from `@DeltaStartUtc`) spanning >= `LongOpenTxnSeconds`.

## Severity rationale

Medium — an open transaction is a risk (log growth, blocking) but not itself an incident.

## Confidence rationale

High — the open-transaction state is directly observed.

## Evidence-type rationale

Observed.

## False-positive risks

A legitimately long batch (ETL) reports; the span is persistence-based, not true elapsed time.

## False-negative risks

A long transaction seen in only one snapshot does not fire; anchored post-restart to avoid session-id reuse.

## Drill-down guidance

Identify the session's transaction and why it stays open; check log reuse (FR_R0022). Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0002_LongRunningOpenTransaction';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`LongOpenTxnSeconds` (default 60). See [configuration.md](../configuration.md).

## Example

Seed a session with open txn in two snapshots >60 s apart.
