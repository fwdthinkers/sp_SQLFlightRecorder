# FR_R0012 BackupOverlapWithIncident

| Field | Value |
|---|---|
| RuleId | `FR_R0012_BackupOverlapWithIncident` |
| Category | Maintenance |
| Severity | Medium |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.2 |
| Lifecycle | Active |
| Data source | `FR_BackupHistory` |
| Dedup anchor | db (D-074) |

## What it detects

A non-log backup that overlapped the incident window.

## How it is computed

Repository-only (D-014/D-081). FULL/DIFF backups overlapping the window; log backups are excluded (D-096).

## Severity rationale

Medium.

## Confidence rationale

High — observed from backupset history.

## Evidence-type rationale

Observed.

## False-positive risks

Backup I/O overlapping an unrelated incident is coincidental.

## False-negative risks

Log backups are excluded by design; very short backups may fall between snapshots.

## Drill-down guidance

Correlate backup I/O with the symptoms; consider scheduling. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0012_BackupOverlapWithIncident';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed FR_BackupHistory with a FULL backup overlapping the window.
