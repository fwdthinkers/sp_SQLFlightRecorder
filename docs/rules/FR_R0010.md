# FR_R0010 FailedSqlAgentJobNearIncident

| Field | Value |
|---|---|
| RuleId | `FR_R0010_FailedSqlAgentJobNearIncident` |
| Category | Maintenance |
| Severity | High |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.2 |
| Lifecycle | Active |
| Data source | `FR_AgentJob` |
| Dedup anchor | db/job (D-074) |

## What it detects

A SQL Agent job that failed near the incident window.

## How it is computed

Repository-only (D-014/D-081). Failed job outcomes from 15 minutes before `@StartTime` through `@EndTime` (D-095).

## Severity rationale

High — a failed job near an incident often explains it.

## Confidence rationale

High — observed from msdb history.

## Evidence-type rationale

Observed.

## False-positive risks

An unrelated failed job in the window is correlated by time, not causation.

## False-negative risks

Jobs outside the 15-minute lead are not considered.

## Drill-down guidance

Review the job's history and step output; correlate its timing with the symptoms. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0010_FailedSqlAgentJobNearIncident';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed FR_AgentJob with RunOutcome='Failed' near the window.
