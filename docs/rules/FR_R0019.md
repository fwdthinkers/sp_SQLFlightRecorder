# FR_R0019 QueryStoreNearingCapacity

| Field | Value |
|---|---|
| RuleId | `FR_R0019_QueryStoreNearingCapacity` |
| Category | QueryStore |
| Severity | Medium |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.3 |
| Lifecycle | Active |
| Data source | `FR_RunLogStep` (QueryStoreCapacity step) |
| Dedup anchor | window (D-074) |

## What it detects

A database's Query Store approached its configured maximum size.

## How it is computed

Repository-only (D-014/D-081). Reads the collect-time capacity percentage (stored in the step's RowsCollected); fires at `QueryStoreCapacityWarnPercent`.

## Severity rationale

Medium.

## Confidence rationale

High — observed from the capacity probe.

## Evidence-type rationale

Observed.

## False-positive risks

A DB near capacity but healthy still reports (a real warning).

## False-negative risks

DBs whose capacity was not probed are not seen.

## Drill-down guidance

Review Query Store retention and max-size settings. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0019_QueryStoreNearingCapacity';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`QueryStoreCapacityWarnPercent`. See [configuration.md](../configuration.md).

## Example

Set the QueryStoreCapacity step RowsCollected above the threshold.
