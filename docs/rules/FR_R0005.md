# FR_R0005 MemoryGrantsPending

| Field | Value |
|---|---|
| RuleId | `FR_R0005_MemoryGrantsPending` |
| Category | Memory |
| Severity | High |
| Confidence | High |
| Evidence type | Observed |
| Introduced in | 0.1 |
| Lifecycle | Active |
| Data source | `FR_Request` (grant columns), `FR_Memory` (corroboration) |
| Dedup anchor | `SessionId` (D-074) |

## What it detects

A request waiting for a query memory grant (requested but not yet granted).

## How it is computed

Repository-only (D-014/D-081). A row with `RequestedMemoryKb > 0` and `GrantedMemoryKb` NULL/0 is a pending grant. `FR_Memory.MemoryGrantsPending` is included as corroboration.

## Severity rationale

High — pending grants mean queries are stalled on memory.

## Confidence rationale

High — the pending-grant state is directly observed.

## Evidence-type rationale

Observed.

## False-positive risks

A momentary grant wait captured in one snapshot reports.

## False-negative risks

Grants that resolve between snapshots are missed.

## Drill-down guidance

Review large-grant queries and MAX_GRANT_PERCENT; correlate with RESOURCE_SEMAPHORE (FR_R0024). Folds into FR_R0024 (§7.13). Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0005_MemoryGrantsPending';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

None. See [configuration.md](../configuration.md).

## Example

Seed a request with RequestedMemoryKb>0 and GrantedMemoryKb NULL.
