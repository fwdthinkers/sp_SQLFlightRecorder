# FR_R0004 FileIoLatencySpike

| Field | Value |
|---|---|
| RuleId | `FR_R0004_FileIoLatencySpike` |
| Category | IO |
| Severity | Medium (escalates High) |
| Confidence | Medium |
| Evidence type | Inferred |
| Introduced in | 0.1 |
| Lifecycle | Active |
| Data source | `FR_FileStat`, `#fr_baseline` |
| Dedup anchor | db+file (D-074) |

## What it detects

A database file whose average read+write stall per I/O is elevated over its recent baseline.

## How it is computed

Repository-only (D-014/D-081). Window delta latency per (db, file) = change in IO stall / change in ops from `@DeltaStartUtc` (D-007, restart-safe). Fires above max(2x baseline, `FileIoLatencyWarnMs`); escalates High above max(4x baseline, 4x floor).

## Severity rationale

Medium, escalating High on large magnitude (by threshold, not row count; D-069 preserved).

## Confidence rationale

Medium, forced Low with <5 baseline samples (D-092).

## Evidence-type rationale

Inferred — latency is consistent with storage pressure but not attributed.

## False-positive risks

A backup or bulk load can raise latency benignly; short windows amplify noise.

## False-negative risks

A counter reset (restart) is excluded; sub-minute spikes are invisible.

## Drill-down guidance

Correlate with PAGEIOLATCH waits (FR_R0003) and backup overlap (FR_R0012); check storage. Drill-down queries are read-only (D-086).

## Suppress / disable

```sql
EXEC dbo.sp_SQLFlightRecorder @Mode = N'Configure',
    @ConfigKey = N'DisabledRules', @ConfigValue = N'FR_R0004_FileIoLatencySpike';
```
Suppressed rules are listed in FR_R0026 (D-101).

## Related config keys

`FileIoLatencyWarnMs` (default 20). See [configuration.md](../configuration.md).

## Example

Seed FR_FileStat with a rising IoStall/ops ratio across two snapshots.
