# Code of Conduct

## Our pledge

We as members, contributors, and maintainers pledge to make participation in
this project a harassment-free experience for everyone, regardless of age, body
size, visible or invisible disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, religion, or sexual identity and
orientation.

## Our standards

Examples of behavior that contributes to a positive environment:

- Being respectful of differing viewpoints and experiences.
- Giving and gracefully accepting constructive feedback.
- Focusing on what is best for the project and its users.

Unacceptable behavior includes harassment, insulting or derogatory comments,
personal or political attacks, publishing others' private information, and other
conduct which could reasonably be considered inappropriate in a professional
setting.

## Enforcement

**Reporting path for v1.0.0.** This project has no separate conduct mailbox.
Conduct reports go to the repository owner,
[@forward-thinkers-lab](https://github.com/forward-thinkers-lab), through the
GitHub maintainer contact channels for this repository — contact the owner
directly via their GitHub profile. If you have no private channel available,
open an issue stating only that you wish to raise a conduct concern and asking
for one, and withhold the details until you have it. **This is the designated
conduct path for v1.0.0**, not a placeholder awaiting replacement.

Do not include private or sensitive information — yours or anyone else's — in a
public issue or discussion.

All complaints will be reviewed and investigated promptly and fairly. The
maintainer is obligated to respect the privacy and security of the reporter.

**A limitation you should know before reporting.** This project is currently
maintained by one person. A report *about* that maintainer cannot be reviewed
independently by this project, and we would rather say so than imply an
impartiality we cannot provide. If that matters for your report, raise it
through a channel outside this project — for example GitHub's own abuse and
spam reporting, which is independent of any repository maintainer. Should the
project gain additional maintainers or move under an organization, conduct
handling moves to that group and this section is revised.
